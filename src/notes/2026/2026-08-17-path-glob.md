Recently I've been getting a lot of use out of the [`glob` module][pydoc-glob], for finding files that match a particular pattern:

```python {"names":{"1":"glob","2":"glob","3":"top_level_html_files","5":"all_html_files"}}
from glob import glob

top_level_html_files = glob("*.html")
all_html_files = glob("**/*.html", recursive=True)
```

But these functions return strings, and I've been trying to use [`Path` objects][pydoc-pathlib] as much as possible.

It turns out the `pathlib` module has [`glob()`][pydoc-pathlib-glob] and [`rglob()`][pydoc-pathlib-rglob] functions that do sometrhing very similar, but they return `Path` objects:

```python {"names":{"1":"pathlib","2":"Path","3":"top_level_html_files","7":"all_html_files"}}
from pathlib import Path

top_level_html_files = Path.cwd().glob("*.html")
all_html_files = Path.cwd().rglob("*.html")
```

This isn't new -- indeed, it's mentioned in [Trey Hunner's 2018 blog post][hunner] that persuaded me to start using `pathlib` -- but somehow I'd forgotten about it.
